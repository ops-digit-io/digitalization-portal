# value-sizing

The Analyst produces a **value hypothesis**, not a promise. Its job is to be
defensible and honest, so the portfolio can prioritise — not to sell. In this portal
every figure carries a **confidence state** and a simulated figure is never presented
as committed.

## Build the estimate

1. **Start from the baseline** (from `problem-framing`). No baseline → no value figure,
   only an open question to quantify it. Never back-fill an invented baseline.
2. **State the mechanism.** How exactly does the solution change the number? "Cuts
   scrap because defects are caught 30 min earlier" — a causal chain a human can
   challenge, not a percentage from the air.
3. **Bound it.** Give a range (conservative / expected) with the assumptions behind
   each, not a single false-precise figure.
4. **Net it.** Subtract the run cost (build, licences, per-call model cost, operating
   effort) — a gross benefit that ignores cost misleads.

## Confidence states (never skip)

- **assumed** — from an intake estimate or benchmark; the default at analysis time.
- **simulated** — from the portal's value simulation on stated assumptions.
- **measured** — proven by a pilot. Only pilots earn this. Committed value requires it.

Label every figure. An assumed figure dressed as measured is the cardinal sin.

## Types of value (name which apply)

- Hard savings (scrap, time→FTE, energy, rework, penalties avoided).
- Revenue / throughput uplift.
- Risk / compliance avoidance (harder to quantify — size the exposure, not a fiction).
- Qualitative / strategic (state it as such; don't fabricate a number for it).

## Rules

- **Never invent a number.** A missing figure is an open question, always.
- **Attribute honestly.** If three initiatives touch the same scrap, don't claim it
  three times.
- **Tie value to the acceptance criteria** — the pilot that measures success should be
  the pilot that converts the value from simulated to measured.

## Output

A value hypothesis: baseline → mechanism → conservative/expected range (net of cost) →
assumptions → confidence state, feeding the business case (S3) and the value model.
Where the baseline is missing, the honest output is the open question, not a guess.
