# Artifact kinds

Pick the kind that proves the riskiest assumption fastest.

| Kind | When it fits | Output |
|---|---|---|
| `dashboard` | The value is in *seeing* a metric that isn't visible today | Self-contained HTML dashboard |
| `app` | The value is a small interactive workflow | Lightweight web app |
| `mockup` | The question is desirability / UX, not feasibility | Clickable UI mockup |
| `report` | The value is an analysis, not a running tool | Markdown analysis report |

All kinds are committed to `poc/` and opened as a pull request — never merged by the portal.
