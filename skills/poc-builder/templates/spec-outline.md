# PoC spec outline

The skeleton `start-poc` fills in. Keep it short; a PoC spec is a falsifiable bet.

- **Goal** — what feasibility/value question this answers.
- **Users** — who reads the result.
- **Scope** — in / out. Evidence only; no production integration.
- **Success criteria** — measured, set before build.
- **Kill criteria** — what would stop this.
- **Deliverable** — the artifact, committed to `poc/`, opened as a PR.
