# Question patterns

Common portfolio questions and how to answer them with `portfolio-query`.

- **"What's stalling?"** → highest days-in-stage; name the stage and the count.
- **"How much work this quarter?"** → total workload (person-weeks); flag if over capacity.
- **"What lands soonest?"** → items whose go-live is within the horizon, by value-per-effort.
- **"Where is the value?"** → pipeline vs committed vs realized, never summed into one figure.

Never answer a question about *who* submits or performs — that view is prohibited.
